# Ubuntu Fingerprint Auth

[English README](README.en.md)

Один запрос **Password or fingerprint** для `sudo` и системных окон GNOME в Ubuntu 26.04. Пароль можно вводить сразу, пока сканер ждёт отпечаток. Таймер ожидания отключён. После трёх неудачных сканирований в открытом запросе остаётся доступен пароль.

## Совместимость

- Ubuntu 26.04 на `amd64` или `arm64`.
- Штатный `sudo-rs` в интерактивном терминале и агент PolicyKit в GNOME.
- Сканер, который уже работает через `fprintd`. Каждый пользователь регистрирует свой отпечаток.

## Установка

Проверьте сканер и определите архитектуру ноутбука.

```bash
fprintd-list "$USER"
fprintd-verify
dpkg --print-architecture
```

Если отпечаток ещё не зарегистрирован, выполните `fprintd-enroll`. Выберите `.deb` для своей архитектуры из артефактов сборки CI или соберите его из исходников. В архиве CI можно проверить пакет командой `sha256sum -c SHA256SUMS`. Имя пакета в APT — `fingerprint-auth-choice`.

```bash
sudo apt install ./fingerprint-auth-choice_3.0-1+ubuntu26.04_amd64.deb
```

На ARM используйте файл с суффиксом `_arm64.deb`. При обновлении через APT пакет устанавливается поверх предыдущей версии с тем же именем.

## Проверка

```bash
sudo -k && sudo -v
pkexec /usr/bin/true
```

Запустите команды по очереди. В каждом запросе введите пароль или приложите палец. Чтобы проверить ожидание сканера, оставьте запрос открытым хотя бы на 15 секунд, затем приложите палец.

`sudo -k` сбрасывает кэш авторизации перед проверкой. Если поле пароля есть, а отпечаток не принимается, проверьте регистрацию и распознавание через `fprintd-verify`.

## Сборка и тесты

На Ubuntu 26.04 выполните из корня репозитория:

```bash
sudo apt install gcc binutils dpkg-dev libpam0g-dev libpam-modules python3
sh src/build.sh dist
sh test/run.sh
python3 -B test/test_configure.py
```

`dist/` содержит готовый `.deb`. Обычные тесты используют фиктивный пароль и сканер. Подключённый сканер можно отдельно проверить под пользователем с зарегистрированным отпечатком:

```bash
FPRINT_TEST_LIVE=1 sh test/run.sh
```

Подробности проверки, кросс-сборки и CI описаны в [CONTRIBUTING.md](CONTRIBUTING.md).

## Удаление

```bash
sudo apt remove fingerprint-auth-choice
```

При удалении пакет восстанавливает исходные конфигурации PAM. Если файлы редактировали после установки, удаляется добавленное пакетом правило, а локальные правки сохраняются.
