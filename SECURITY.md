# Security

This package runs inside authentication processes. Report suspected authentication bypasses, credential exposure, or privilege escalation privately to the repository maintainer. If the repository is on GitHub and private reports are enabled, use its **Security → Report a vulnerability** link.

Include the package version, Ubuntu release, processor architecture, service (`sudo`, `sudo-i` or `polkit-1`), and steps that reproduce the issue in a test environment. Omit passwords, fingerprint templates and unrelated authentication logs.
